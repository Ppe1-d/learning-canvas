# Learning Canvas · 学习画布

将学习问答整理成可分支、可关联的画布。支持独立启动、兼容 Chat Completions 的 API、可选 Codex，以及 DSH 导出记录导入。

**AI 辅助说明：本项目的需求讨论、代码实现、测试和文档使用了 OpenAI Codex 辅助。项目非 OpenAI 或 DeepSeek 官方产品，目前为实验版本。**

## 启动（Windows）

1. 安装 Node.js 24 或更新版本。
2. 下载仓库 ZIP 并解压到可写目录。
3. 双击 `Open-Canvas.cmd`，自动启动本地服务并在默认浏览器打开。

没有第三方 npm 依赖，不需要先安装 Codex 或 DSH。也可运行 `npm start`。当前自动打开浏览器的脚本仅支持 Windows；其他系统可运行 `node server.mjs`，手动打开终端显示的地址。

首次启动创建本地课程。服务仅监听 127.0.0.1；启动令牌换成本地 Cookie 后会从地址栏清除。服务重启可能更换端口，请重新使用启动文件。关闭网页不会停止后台服务。

## 配置模型

顶栏菜单 → 模型服务，填写名称、接口地址、模型 ID 和密钥。接口支持 `/chat/completions`；例如地址填 `https://api.deepseek.com`。思考参数类型需按服务文档选择，不会自动识别模型能力。未启用 Codex 时不会查询它的模型目录。

输入框下方分别设置生成和审校模型、思考强度及提示词。选择“生成并审校”会执行两次独立请求，产生实际服务用量；“直接生成”只执行一次请求，可在审校设置中关闭审校；“仅预览上下文”不调用模型。API 模式不提供或执行任何工具。

草稿仅用于第二阶段审校；只有最终稿进入后续问答上下文。审校失败会保留草稿供重试，不能继续引用未完成答案。审校并不保证回答正确，也不代表已执行代码或检索外部资料。

## Codex 和 DSH

- Codex 为可选项：安装并登录 Codex CLI 后，在模型服务中启用。调用使用独立临时目录和受限配置；不等同于直接调用 GPT API，也不继承桌面聊天的全部工具。可用模型和调用权限取决于 CLI 与账户。
- 导入当前 Codex 聊天：在具有 `CODEX_THREAD_ID` 环境变量的 Codex 任务中执行 `node open-current-thread.mjs`。只导入已完成问答，保留画布自己的分支和布局。
- DSH：从 DSH 导出会话日志 ZIP，解压后，在课程切换菜单选择“导入 DSH”，选择 `session.v4.jsonl`。当前是历史问答导入，不是 DSH 实时工具接入；不支持原始压缩日志、旧格式或工具状态恢复。导入适配使用 v4 格式合成样本测试，尚未完成真实用户导出文件的端到端验证。

## 画布与资料

拖动空白处平移，滚轮缩放；拖动卡片改变位置。连线从卡片边缘端口出入，可横向或纵向整理。点击卡片展开阅读栏，多选可关联提问，分支不会自动进入主线上下文。

资料目录由用户主动绑定，仅读取支持的文本格式；规则可关闭、完整读取或自定义，不修改原 AGENTS.md。生成时选中的资料片段会发送给所配置的模型服务。当前不解析 PDF、Word 或图片。

## 本地数据

`data/` 保存课程、聊天记录、资料快照、运行信息和连接配置。**API 密钥以明文保存在本机 `data/connections.json`，没有系统密钥库加密。** 不要提交、上传或转发该目录。课程导出 JSON 可能包含聊天及资料片段和本地路径，分享前请检查。

配置给网页的服务列表不包含密钥；节点保存服务参数快照，不保存密钥。不要将本地服务暴露到公网。本仓库不附带开发者的聊天、密钥或截图。

## 开发与验证

运行 `npm test`。当前 29 项测试覆盖上下文隔离、两阶段结果、模型配置、API 密钥脱敏、无 Codex 独立调用、DSH 过滤、Cookie 会话、Markdown 与连线布局。API 测试使用本机模拟服务，不证明所有第三方服务均兼容。

主要模块：`server.mjs` 本地路由与任务；`core.mjs` 课程上下文及持久化；`generation.mjs` 两阶段配置；`review.mjs` 两阶段执行；`api-provider.mjs` 文本 API；`connections.mjs` 服务配置与分发；`codex-provider.mjs` 可选 CLI；`dsh-import.mjs` DSH 导入；`launcher.mjs` 启动；`public/` 网页与画布。

添加服务时优先扩展 API 适配层，保持密钥不进入网页状态、草稿不进入后续上下文的约束。

## Codex 连接修复

Windows 会优先使用 CANVAS_CODEX_BIN，其次查找 PATH 和桌面端本机安装目录中的 codex.exe。登录仍由官方 CLI 管理：首次使用可运行 `codex login`，并用 `codex login status` 检查。无需复制凭据到画布。

“我的画布”打开已保存记录，不触发 Codex 同步；选择“Codex 聊天”并打开课程才同步原聊天。画布新增内容不写回 Codex。

## 阅读与可选摘要

输入框上方显示主线、分支或关联目标，点击目标可回到主线。卡片标题和摘要均可拖动；阅读栏分隔线使用灰色，松手后恢复正常状态。回答方式采用深色菜单。

顶栏菜单 → 阅读设置，可调整字体、正文大小、行距及卡片摘要大小，偏好保存在当前浏览器。

顶栏菜单 → 历史摘要，默认关闭。开启后采用“较早历史摘要＋最近若干轮完整问答”，默认保留最近 8 轮，可设置 1–50 轮。原始问答始终保留，节点的“本次上下文”可查看实际发送的摘要和完整近期历史，并展开原始路径。

摘要保留学习进度、关键结论、未解决问题和必要的表达偏好，区分已讲解与已验证掌握。点击生成预览会额外调用一次生成模型；可查看、修改后再应用。不会后台自动更新或覆盖手动修改。历史继续增长后，尚未总结的新轮次继续完整发送，直到手动更新摘要。

摘要只适用于内容匹配的路径前缀，分支不会混入主线。没有适用摘要时使用完整历史；生成失败不替换已有摘要。设置和摘要的修改只影响之后创建的请求，已有节点保留其上下文快照。
